# AGENTS

## Language Requirements

- Write and maintain `AGENTS.md` in English.
- Write all Git commit messages in English.
- Maintain project documentation in both English and Simplified Chinese:
  - `README.md`: English.
  - `README.zh-CN.md`: Simplified Chinese.
- Keep both README versions consistent when updating their content, and include a link to the other language version in each file.
